# NILO Racing

Live HUD-overlay en sessieanalyse voor Assetto Corsa en ACC.

Deze repository bevat alleen de installers. De app kijkt hier zelf of er een
nieuwe versie is, haalt die op de achtergrond binnen en installeert hem als je
NILO Racing afsluit.

## Installeren

Download de nieuwste `NILO-Racing-Setup-*.exe` onder
[Releases](https://github.com/Automatiseer-Jouw-Proces/nilo-racing-releases/releases/latest)
en start hem. Windows waarschuwt omdat de installer niet ondertekend is:
klik op **Meer info → Toch uitvoeren**.

Daarna werkt de app zichzelf bij.
